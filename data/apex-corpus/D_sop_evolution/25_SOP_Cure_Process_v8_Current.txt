1. PURPOSE
This procedure defines the standard operating parameters and steps for
the thermal curing operation on Press-07 (Equipment: PX-400, Asset 7714).

2. SCOPE
Applies to all production operators running Press-07 for PC-Series
precision polymer housing production.

3. SAFETY
Standard PPE required. Do not exceed cure zone upper control limit
(see Section 4). High-temp alarm indicates immediate operator action
required per Section 6.

4. PROCESS PARAMETERS
  Cure zone target temperature: 38.5 deg C
  Cure zone upper control limit (UCL): 42.3 deg C
  Cure zone lower control limit (LCL): 36.0 deg C
  Cure time: 85 sec nominal
  Cycle pressure: 2.1-2.7 bar

  [System field "Parameter Basis Reference": not populated for this
  parameter in current QMS-2022 record.]

5. OPERATING PROCEDURE
  5.1 Verify controller display shows "READY" and setpoint matches
      Section 4 values.
  5.2 Load part per work instruction WI-CURE-07-B.
  5.3 Initiate cure cycle.
  5.4 Monitor controller display for alarm conditions.
  5.5 Unload part on cycle completion; visually inspect per QC-CHK-04.

6. ALARM RESPONSE
  If high-temp alarm activates (cure zone exceeds 42.3 deg C):
    a) Do not open press mid-cycle.
    b) Allow controller auto-correction.
    c) If temperature does not return below UCL within 5 min, stop
       production and notify Maintenance and Process Engineering.
    d) Log the event per Maintenance work order procedure.
