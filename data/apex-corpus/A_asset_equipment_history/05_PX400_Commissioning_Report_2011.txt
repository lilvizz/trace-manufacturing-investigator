APEX THERMAL COMPONENTS -- CHENNAI PLANT 2
COMMISSIONING REPORT

Report No: COMM-2011-057                             Date: 2011-08-22
Prepared by: T. Balakrishnan, Equipment Engineer
Related ECO: ECO-2011-184
Equipment: PX-400 (Halberd Process Systems), Serial No HPS-PX400-1187
Location: Press-07, Line 7, Asset 7714

1. PURPOSE
To verify mechanical, electrical, and baseline process functionality of the
newly installed PX-400 unit prior to formal process qualification.

2. EQUIPMENT RATED SPECIFICATIONS (per vendor manual v4)
  Cure zone temp range (rated): 10 - 70 deg C
  Controller: HPS-CTRL v3.2, PID auto-tune enabled
  Sensor type: RTD (Pt100) x4 (upgrade from PX-200's thermocouple array)

  Note: Rated range is wider than the PX-200 unit it replaces, consistent
  with the newer platform's improved thermal management design. This report
  covers baseline commissioning only; process qualification against
  production requirements is addressed separately (see Qualification Report,
  PX400_Qualification_2011).

3. COMMISSIONING TESTS PERFORMED
  3.1 Mechanical alignment check .......... PASS
  3.2 Electrical/control loop check ........ PASS
  3.3 Sensor calibration verification ...... PASS (all 4 RTDs within +/-0.2 deg C
                                               of reference standard)
  3.4 Baseline thermal run (within existing
      SOP-CURE-07 v5 setpoints, i.e. up to
      42.3 deg C UCL) ........................ PASS, stable, no excursions
      over 72-hr continuous run

4. SCOPE LIMITATION
  This commissioning exercise verified stable operation WITHIN the existing
  process envelope (up to 42.3 deg C). It did not test operation above this
  limit, as the objective was equipment-swap continuity, not process
  parameter expansion. Any assessment of the equipment's capability beyond
  the existing envelope would require a separate study.

5. RESULT
  PX-400 unit is fit for production use within existing SOP-CURE-07 v5
  parameters. Recommend proceeding to formal process qualification.
